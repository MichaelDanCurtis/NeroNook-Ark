# Ark module
An independent native NeroNook plugin. No companion application, installed CLI, Python, local server or other plugin may be required. Use the vendored SDK; no Samsung code in NeroNook core. Device transport and credentials live here. Talk only to an explicitly selected local monitor, verify its advertised Samsung/Ark identity and pin its device ID before commands. Do not reuse browser credentials. Keep HTTP/UPnP read-back separate from unacknowledged remote-key transmission. Capability discovery gates controls. No automatic replay of device commands. Do not change inputs/power during acceptance; same-value volume/mute writes suffice. Pairing approval happens on the physical monitor. Keep tokens in Keychain and out of logs and snapshots. Original 16:9 vector dashboard, a single compact status line and native settings. Test identity, XML/JSON parsing, command validation and unavailable states; verify real readings and native UI separately.
